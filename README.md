# 🛠️ TCP Echo Server — Golang

A simple TCP server built in Go that listens on a specified port and echoes back any message received from connected clients. This project demonstrates fundamental networking concepts such as sockets, concurrency with goroutines, and message streaming in Go.

---

## 🚀 Features

- Accept multiple client connections concurrently
- Echo back messages received from clients
- Line-based message handling using buffered I/O
- Simple and clean architecture
- Customizable port via command-line argument
